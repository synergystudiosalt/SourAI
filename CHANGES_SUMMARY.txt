FEATURE 3: SUBAGENT IMAGE UPLOAD & SMART FUNCTIONS
───────────────────────────────────────────────────

What It Does:
A. Image Upload Button
   - Click image icon (🖼️) in input toolbar
   - Reuses existing AttachmentPopover component
   - Images attached for visual context
   - Subagents pass images to parent agent

B. Smart Function Auto-Detection
   Pattern 1: ReadFile
   - Keywords: read, view, show, open, check, display, cat
   - Auto-calls: @@readfile when file path detected
   - Example: "read src/App.tsx" → auto-calls @@readfile
   
   Pattern 2: FindAll
   - Keywords: search, find, locate, grep, look for, where
   - Auto-calls: @@findall when search term detected
   - Example: "find all imports" → auto-calls @@findall

C. Complex Task Detection
   - Detects when task is complex (word count > 60 + 2 sentences)
   - Or when has multiple topics (and, also, plus, additionally)
   - Auto-spawns subagents for parallel work
   - Display: "_[Complex task detected — spawning subagents...]_"

D. Auto-Called Functions Display
   - When functions are auto-called, UI shows:
   - "_[Auto-called: @@readfile, @@findall]_"
   - User knows exactly what agent did autonomously

Key Code:
- autoDetectAndCallFunctions() - Regex pattern matching
- shouldAutoSpawnSubagents() - Complexity analysis
- Regex patterns: O(m) where m = message length
- Overhead: <2ms per message

New State:
- showAttachmentPopover: boolean
- attachmentPopoverRef: React.RefObject
- useEffect for click-outside detection
